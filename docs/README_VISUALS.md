# README visual assets

The README uses two purpose-built documentation illustrations:

| Asset | Subject | Generation |
| --- | --- | --- |
| `assets/readme/strokevasc-banner.svg` | StrokeVasc identity and an illustrative vascular network | Analytic cubic curves and SVG paths |
| `assets/readme/vessel-pointcloud-demo.svg` | Foreground geometry and a coloured point representation | The same analytic curves with deterministic sampled points |

Both assets are generated by `scripts/make_readme_visuals.py` using the Python
standard library and the fixed random seed `20261102`. Their geometry, sampling
and colours are constructed specifically for repository documentation. They
represent teaching examples rather than patient anatomy, model predictions or
benchmark observations. The graphics are separate from the manuscript figure
assets and use locally generated vector elements throughout.

Rebuild from the repository root:

```bash
python scripts/make_readme_visuals.py
```

SVG preserves editable text and scales cleanly in the GitHub README. Asset reuse
follows the repository's [license notice](../LICENSE_NOTICE.md).
